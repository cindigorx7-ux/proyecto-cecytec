Bienvenidos

Esta página web fue creada para presentar el Proyecto Transversal desarrollado en nuestra institución educativa. Aquí podrás encontrar información, investigaciones, imágenes, infografías, trípticos y el presupuesto elaborado durante el proyecto.

Acerca del Proyecto

El proyecto transversal busca integrar diferentes asignaturas para desarrollar habilidades tecnológicas, creatividad y trabajo en equipo mediante herramientas digitales.

Objetivos

  • Desarrollar habilidades digitales.
  • Fomentar el trabajo colaborativo.
  • Aplicar conocimientos tecnológicos.
  • Diseñar una página web educativa.

Investigación

La tecnología ha cambiado la forma en que las personas investigan y analizan información. Actualmente, las páginas web permiten acceder rápidamente a contenido educativo, recursos multimedia y herramientas de aprendizaje.

Importancia de las páginas web

  • Acceso rápido a información.
  • Comunicación eficiente.
  • Difusión de proyectos.
  • Aprendizaje interactivo.
  • Desarrollo tecnológico.
